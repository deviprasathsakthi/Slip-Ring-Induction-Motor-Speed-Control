Analysis of Speed Control Performance of Slip-Ring Induction Motor

Project Overview

This project focuses on analysing the speed control performance of a slip-ring induction motor using an IGBT-based drive.

The study investigates motor speed control using power electronic converters and evaluates the motor's performance under different operating conditions.

Project Objectives

- Study the working principle of a slip-ring induction motor.
- Analyse speed control using an IGBT-based drive.
- Understand power electronic switching techniques.
- Study motor speed and performance characteristics.
